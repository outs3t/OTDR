Procedura di Conversione in .SOR

Segui questi passaggi per trasformare il file CSV grezzo in un certificato OTDR valido al 100%.

1Scarica il Software Viewer

Hai bisogno di un visualizzatore professionale (Trial o Free). Consigliati:
- EXFO FastReporter 3 (Standard industriale)
- Yokogawa AQ7932 o Viewer gratuito
- Viavi FiberTrace

2Importa il CSV

Nel software vai su File > Import > ASCII/Text/CSV.
Seleziona il file scaricato da questo strumento.

3Imposta le Colonne

Il software chiederà come leggere i dati:
- Colonna X (Distanza): Imposta unità su km.
- Colonna Y (Potenza): Imposta unità su dB.

4Inserisci i Parametri Fisici

Per rendere il file legittimo, riempi le "Trace Properties":
- Wavelength: 1310 nm o 1550 nm
- IOR (Indice Rifrazione): 1.46700 (Standard G.652)
- Pulse Width: 100 ns (o in base alla lunghezza)

5Salva come .SOR

Vai su File > Save As... e seleziona il formato Telcordia (.SOR).
Il software calcolerà automaticamente i checksum di sicurezza.
